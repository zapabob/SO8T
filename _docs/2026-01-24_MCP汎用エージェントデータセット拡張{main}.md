## データセット構造

各汎用エージェントデータセットは以下の構造を持ちます：

```python
{
    'text': str,  # メインのテキストコンテンツ
    'instruction': str,  # タスク指示
    'input': str,  # 入力データ
    'output': str,  # 期待される出力
    'type': str,  # データセットタイプ（general_agent_business等）
    'category': str,  # カテゴリ（経営分析、コード生成等）
    'difficulty': str,  # 難易度（basic/intermediate/advanced）
    'tools': List[str],  # 使用するツール/APIのリスト（空リストも含む）
    'tool_condition': str,  # ツール使用条件（required/optional/forbidden/no_tool）
    'tool_failure': Optional[Dict],  # ツール失敗例とリカバリ手順
    'uncertainty_label': Optional[str],  # 不確実性ラベル（certain/inferred/unknown）
    'thinking': str,  # 思考プロセス（/thinking形式）
    'delivery_format': Optional[str],  # 最終納品形式（table/csv/pdf/slide/email/text）
}
```
