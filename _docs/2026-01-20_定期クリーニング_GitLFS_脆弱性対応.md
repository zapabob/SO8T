```python
    def cleanup_temp_dirs(self)        # 一時ディレクトリ削除
    def cleanup_cache_dirs(self)       # キャッシュ削除
    def cleanup_old_logs(self, days=30) # 古いログ削除
    def cleanup_build_artifacts(self)   # ビルドアーティファクト削除
    def cleanup_large_temp_files(self)  # 大容量ファイル削除
```

### Git LFS設定仕様
```gitattributes
# Large model files
*.gguf filter=lfs diff=lfs merge=lfs -text
*.safetensors filter=lfs diff=lfs merge=lfs -text
*.bin filter=lfs diff=lfs merge=lfs -text

# Exclude temp files
temp_*/** -filter -diff -merge
__pycache__/** -filter -diff -merge
```
