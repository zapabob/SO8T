# 2026-02-08 BioRxiv 重複取得問題の修正ログ

## 問題点

BioRxiv の論文が、スキップ機能が有効であるにも関わらず再起動のたびに再取得されていた。

## 原因分析

1. **ID生成の不整合**: `structure_paper_data` では BioRxiv 論文に対しても `arxiv_` プレフィックスを付けていたが、Arxiv ID がない場合は `arxiv_unknown` になり、一意性が保たれていなかった。
2. **フィルタリングロジックのミス**: `process_top_cited_papers` 内のフィルタリングでは `arxiv_` + `biorxiv_doi` で判定しようとしていたが、保存時の ID と一致していなかった。
3. **コードの重複**: `get_existing_paper_ids` メソッドがクラス内で二重定義されていた。

## 修正内容

1. **一貫したID生成**:
   - Arxiv ID がある場合は `arxiv_{arxiv_id}`。
   - BioRxiv 固有（Arxiv ID なし）の場合は `biorxiv_{doi}` を ID とするように統一。
2. **フィルタリングの同期**: `process_top_cited_papers` での既読チェックも上記と同じ ID 生成ルールに従うように修正。
3. **二重定義の削除**: `get_existing_paper_ids` の重複を整理し、環境変数 `SO8T_SKIP_EXISTING` に対応した最新版に統合。

## 検証

- BioRxiv 論文が `biorxiv_DOI` という形式で保存されるようになり、次回の検索・取得時に正しく `existing_ids` とマッチしてスキップされるようになります。
