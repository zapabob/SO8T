# タスクスケジューラ電源投入時自動起動システム実装ログ

## 実装情報
- **日付**: 2025-12-01
- **Worktree**: main
- **機能名**: タスクスケジューラ電源投入時自動起動システム
- **実装者**: AI Agent

## 実装概要

**Windowsタスクスケジューラ**を使って、電源投入時にSO(8)Tパイプラインが自動起動するシステムを実装しました。

これにより、システム起動時に自動的にSO(8)T学習プロセスが開始され、電源復旧時の自動再開機能と連携して、24時間365日の連続学習が可能になります。

## 実装アーキテクチャ

### 1. メイン起動スクリプト

**ファイル**: `scripts/startup/so8t_power_on_startup.bat`

#### 機能概要
- 電源投入時のSO(8)Tパイプライン自動起動
- 詳細なログ記録
- 環境設定とプロセス管理
- GPU/プロセス状態確認
- 成功/失敗時の音声通知

#### スクリプト仕様
```batch
@echo off
REM SO(8)T Power-On Startup Script

REM 作業ディレクトリ設定
cd /d "C:\Users\downl\Desktop\SO8T"

REM Python環境設定
set PYTHONPATH=%PYTHONPATH%;"C:\Users\downl\Desktop\SO8T"
set SO8T_AUTO_RECOVER=true
set SO8T_AUTO_CLEANUP=true

REM バックグラウンド実行
start "SO8T_Automated_Pipeline" /B python so8t_automated_pipeline.py --autostart

REM プロセス起動確認・GPU確認・ログ記録
```

#### ログ機能
- **ログファイル**: `logs/startup/so8t_startup_YYYYMMDD_HHMMSS.log`
- **記録内容**:
  - 起動時刻・コンピュータ名・ユーザー名
  - Pythonプロセス起動確認
  - GPU利用可能性
  - エラー詳細

### 2. タスクスケジューラ設定スクリプト

**ファイル**: `scripts/startup/setup_task_scheduler.bat`

#### 機能概要
- タスクスケジューラへのSO8Tタスク自動登録
- 管理者権限チェック
- 既存タスクの削除と新規作成
- タスク作成結果の検証

#### タスク設定仕様
```batch
schtasks /create /tn "SO8T_Power_On_Startup" ^
    /tr "\"%STARTUP_SCRIPT%\"" ^
    /sc ONLOGON ^
    /rl HIGHEST ^
    /delay 0000:30 ^
    /f
```

**タスクパラメータ**:
- **名前**: SO8T_Power_On_Startup
- **トリガー**: ONLOGON (ログオン時)
- **実行権限**: HIGHEST (最高権限)
- **遅延**: 30秒 (システム安定化待ち)
- **強制実行**: /f (既存タスク上書き)

### 3. タスク削除スクリプト

**ファイル**: `scripts/startup/remove_task_scheduler.bat`

#### 機能概要
- タスクスケジューラからのSO8Tタスク削除
- ログファイルのクリーンアップオプション
- 削除結果の検証

### 4. テストスクリプト

**ファイル**: `scripts/startup/test_startup.bat`

#### 機能概要
- タスクスケジューラ設定の総合テスト
- Python環境・GPU・ログディレクトリの確認
- セットアップ状況の診断

```
   ├── 名前: SO8T_Power_On_Startup
```


## 技術的特徴

### 1. 堅牢な起動プロセス

#### 環境設定
```batch
REM Python環境設定
set PYTHONPATH=%PYTHONPATH%;"C:\Users\downl\Desktop\SO8T"
set SO8T_AUTO_RECOVER=true
set SO8T_AUTO_CLEANUP=true
```

#### バックグラウンド実行
```batch
start "SO8T_Automated_Pipeline" /B python so8t_automated_pipeline.py --autostart
```

- **/B**: バックグラウンド実行（コンソール非表示）
- **プロセス分離**: 起動スクリプト終了後も継続実行

#### プロセス検証
```batch
tasklist /FI "IMAGENAME eq python.exe" | find "python.exe"
```

- **起動確認**: Pythonプロセス存在チェック
- **タイムアウト**: 5秒待機後確認

### 2. 詳細な監視・ログ機能

#### ログフォーマット
```batch
set LOG_FILE=%LOG_DIR%\so8t_startup_%DATE:~0,4%%DATE:~5,2%%DATE:~8,2%_%TIME:~0,2%%TIME:~3,2%%TIME:~6,2%.log
```

- **日時スタンプ**: YYYYMMDD_HHMMSS形式
- **ファイル名正規化**: スペース除去

#### ログ内容
- 起動時刻・環境情報
- プロセス起動状態
- GPU利用可能性
- エラー詳細（発生時）

### 3. タスクスケジューラ最適化

#### トリガー設定
- **ONLOGON**: 任意ユーザーログオン時起動
- **遅延30秒**: システム起動競合回避

#### 権限設定
- **HIGHEST**: 管理者権限で実行
- **安定性確保**: GPU・システムリソースアクセス

#### エラーハンドリング
- **既存タスク削除**: /f オプションで強制上書き
- **作成結果検証**: schtasks /query で確認

### 4. テスト・診断機能

#### 総合テスト項目
1. **タスク存在確認**: Task Scheduler登録状態
2. **スクリプト存在確認**: ファイル配置状態
3. **Python環境確認**: 実行環境状態
4. **GPU確認**: CUDA/GPU利用可能性
5. **ログディレクトリ確認**: 保存先状態

#### セットアップ診断
- 不足コンポーネントの自動検出
- 修正手順の自動表示
- 代替セットアップ方法の提示
