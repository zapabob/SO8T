# 2026-02-08 習得済みデータスキップ機能及び並列収集の実装ログ

## 概要

データ収集・加工パイプラインにおいて、既に処理済みの論文をスキップする機能を追加し、複数のデータソースからの収集を効率化するために並列実行（並行処理）を導入しました。

## 実装内容

### 1. 習得済みデータスキップ機能

- **対象**: `Arxiv/BioRxiv` 及び `Semantic Scholar`
- **内容**:
  - `data/arxiv_biorxiv/cleaned/` ディレクトリ内の既存の `.jsonl` ファイルをスキャンし、過去に処理された全論文ID（Arxiv ID等）をロード。
  - 検索結果と照合し、既に存在する論文はダウンロード・PDF抽出・加工をスキップ。
  - 環境変数 `SO8T_SKIP_EXISTING=1` (デフォルト) で有効化、`0` で無効化（全件再処理）が可能。

### 2. 並列収集の統合

- **ファイル**: `src/infrastructure/pipeline/integrated_moonshot_pipeline_2025_2026.py`
- **内容**:
  - `subprocess.Popen` を使用し、`process_arxiv_biorxiv.py` と `semanticscholar_fetcher.py` を同時に起動。
  - 取得とVSSI形式への加工を同時に行い、パイプラインの全体実行時間を短縮。

### 3. PDF破損自動修復

- **内容**: `PDFplumber` 及び `PyPDF2` で抽出に失敗した（破損している可能性が高い）PDFファイルを自動的に削除。次回の実行時に再ダウンロードが試行される「自己修復」を実現。
