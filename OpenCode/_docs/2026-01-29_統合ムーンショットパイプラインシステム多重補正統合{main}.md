### 1. 多重比較補正

#### Bonferroni補正
- **方法**: α/m (m=比較数)
- **特徴**: 保守的で最も厳格
- **適用**: 複数のベンチマークでt検定を実行する場合

```python
def apply_multiple_comparison_correction(p_values: Dict[str, float], 
                                        method: str = 'bonferroni'):
    if method == 'bonferroni':
        n_comparisons = len(p_values)
        alpha = 0.05 / n_comparisons
        corrected_p_values = {k: min(v * n_comparisons, 1.0) 
                            for k, v in p_values.items()}
        return {
            'corrected_p_values': corrected_p_values,
            'alpha': alpha,
            'method': 'bonferroni',
            'n_comparisons': n_comparisons
        }
```

#### FDR補正（Benjamini-Hochberg法）
- **方法**: p値×n/rank (rank=ソート順位)
- **特徴**: 偽発見率を制御、Bonferroniより検出力が高い
- **適用**: 多くの比較を行う場合に推奨

```python
elif method == 'fdr':
    sorted_p = sorted(p_values.items(), key=lambda x: x[1])
    n = len(sorted_p)
    corrected_p_values = {}
    
    for i, (benchmark, p_value) in enumerate(sorted_p):
        rank = i + 1
        corrected_p = min(p_value * n / rank, 1.0)
        corrected_p_values[benchmark] = corrected_p
```

#### Holm-Bonferroni補正
- **方法**: ステップダウン法、逆順ランクで補正
- **特徴**: Bonferroniより検出力が高いが、FDRより保守的
- **適用**: 中間的な厳格さが必要な場合

```python
elif method == 'holm':
    sorted_p = sorted(p_values.items(), key=lambda x: x[1])
    n = len(sorted_p)
    corrected_p_values = {}
    
    for i, (benchmark, p_value) in enumerate(sorted_p):
        rank = n - i  # 逆順ランク
        corrected_p = min(p_value * rank, 1.0)
        corrected_p_values[benchmark] = corrected_p
```

### 2. ABCテストへの統合

```python
async def execute_scientific_abc_test(config: Dict):
    """科学的厳密性のあるABCテスト（多重比較補正付き）"""
    results = {}
    all_p_values = {}
    
    # ... 評価実行 ...
    
    # 多重比較補正適用
    correction_method = config.get("correction_method", "bonferroni")
    correction_results = apply_multiple_comparison_correction(
        all_p_values, 
        method=correction_method
    )
    
    # 補正後の有意性判定
    for benchmark, corrected_p in correction_results["corrected_p_values"].items():
        results["C"][benchmark]["corrected_p_value"] = corrected_p
        results["C"][benchmark]["significant_after_correction"] = (
            corrected_p < correction_results["alpha"]
        )
    
    return {
        "results": results,
        "correction": correction_results
    }
```

## 統計的厳密性の向上

### 多重比較問題
複数のベンチマークでt検定を実行する場合、Type Iエラー（偽陽性）の確率が増加します。

**例**: 5つのベンチマークでα=0.05で検定する場合
- **補正なし**: 少なくとも1つの偽陽性が発生する確率 ≈ 22.6%
- **Bonferroni補正**: α = 0.05/5 = 0.01 で検定 → 偽陽性率 ≈ 4.9%
- **FDR補正**: 偽発見率を制御 → より検出力が高い

### 補正方法の選択

| 方法 | 厳格さ | 検出力 | 推奨用途 |
|------|--------|--------|----------|
| Bonferroni | 最高 | 最低 | 少数の比較、厳格な制御が必要 |
| Holm-Bonferroni | 中 | 中 | 中間的な厳格さが必要 |
| FDR (BH) | 低 | 最高 | 多くの比較、探索的研究 |
