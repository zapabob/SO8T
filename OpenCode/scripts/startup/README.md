# SO(8)T Power-On Auto Startup

このディレクトリには、Windowsタスクスケジューラを使って電源投入時にSO(8)Tパイプラインを自動起動するためのスクリプトが含まれています。

## 概要

SO(8)Tパイプラインは、電源復旧時自動再開機能を備えています。このシステムにより、予期せぬ電源断が発生しても、学習の進行状況を保持し、電源復旧時に自動的に中断箇所から再開することができます。

## ファイル構成

- `so8t_power_on_startup.bat` - 電源投入時に実行されるメインスクリプト
- `setup_task_scheduler.bat` - タスクスケジューラに自動起動を設定するスクリプト
- `remove_task_scheduler.bat` - タスクスケジューラから自動起動を削除するスクリプト

## インストール手順

### 1. 管理者権限での実行

**重要**: 以下の全てのスクリプトは**管理者権限**で実行してください。

### 2. タスクスケジューラ設定

```cmd
# 管理者権限のコマンドプロンプトで実行
setup_task_scheduler.bat
```

このスクリプトは以下の処理を行います：
- 既存のSO8Tタスクを削除（存在する場合）
- 新しいタスク「SO8T_Power_On_Startup」を作成
- ログオン時（電源投入時）に自動起動するよう設定

### 3. 設定確認

タスクスケジューラが正しく設定されたことを確認：

1. Windows検索で「タスクスケジューラ」と入力
2. 「タスクスケジューラ」を開く
3. 左側の「タスクスケジューラライブラリ」を選択
4. 「SO8T_Power_On_Startup」が表示されていることを確認

## タスク設定の詳細

### トリガー
- **種類**: ログオン時
- **設定**: 任意のユーザー
- **遅延**: 30秒

### アクション
- **種類**: プログラムの開始
- **プログラム/スクリプト**: `C:\Users\downl\Desktop\SO8T\scripts\startup\so8t_power_on_startup.bat`
- **開始位置**: `C:\Users\downl\Desktop\SO8T`

### 条件
- **電源**: 電源に接続されている場合のみタスクを開始する（チェックなし）
- **スリープ状態**: スリープを解除したときにタスクを開始する（チェックなし）

### 設定
- **最高の特権で実行**: チェックあり
- **タスクの停止**: 3日後に停止（チェックなし）
- **強制的に停止**: チェックなし

## 動作フロー

### 電源投入時

```
1. Windows起動
2. ユーザーログオン
3. タスクスケジューラが30秒待機
4. so8t_power_on_startup.bat 実行
5. Python環境設定
6. SO8Tパイプライン起動 (--autostart)
7. ログ記録・GPU確認
8. 音声通知（成功時）
```

### ログファイル

起動ログは以下の場所に保存されます：
```
logs/startup/so8t_startup_YYYYMMDD_HHMMSS.log
```

ログには以下の情報が記録されます：
- 起動時刻・コンピュータ名・ユーザー名
- Pythonプロセスの起動確認
- GPU利用可能性
- エラー発生時の詳細

## トラブルシューティング

### タスクが実行されない

1. **管理者権限の確認**
   - スクリプトを管理者として実行したか確認

2. **タスクステータスの確認**
   ```cmd
   schtasks /query /tn "SO8T_Power_On_Startup"
   ```

3. **イベントログの確認**
   - イベントビューアー → Windowsログ → システム
   - タスクスケジューラ関連のエラーを確認

4. **手動テスト**
   ```cmd
   so8t_power_on_startup.bat
   ```

### Pythonプロセスが起動しない

1. **Pythonパスの確認**
   - `python --version` でPythonが利用可能か確認

2. **環境変数の確認**
   - PYTHONPATHが正しく設定されているか確認

3. **ログファイルの確認**
   - `logs/startup/` 内のログファイルを確認

### GPUが利用できない

1. **GPUドライバの確認**
   - NVIDIAコントロールパネルでドライバを確認

2. **CUDAの確認**
   - `nvidia-smi` コマンドが利用可能か確認

## 設定のカスタマイズ

### 遅延時間の変更

タスクスケジューラのGUIで遅延時間を変更できます：
- タスクスケジューラ → SO8T_Power_On_Startup → トリガー → 編集
- 「詳細設定」→「遅延」を変更

### ログレベルの変更

`so8t_power_on_startup.bat` を編集してログ出力をカスタマイズできます。

### 環境変数の追加

スクリプト内の環境変数を追加/変更できます：
```batch
set SO8T_AUTO_RECOVER=true
set SO8T_AUTO_CLEANUP=true
set CUSTOM_VAR=value
```

## アンインストール

自動起動を無効にする場合：

```cmd
# 管理者権限のコマンドプロンプトで実行
remove_task_scheduler.bat
```

このスクリプトは：
- タスクスケジューラからSO8Tタスクを削除
- 起動ログファイルの削除オプションを提供

## セキュリティ考慮事項

- **管理者権限**: タスクは最高の特権で実行されます
- **パスワードなし**: ログオン時に自動実行するため、パスワードは不要
- **ログ管理**: 起動ログは定期的に確認・削除してください

## 代替方法

タスクスケジューラ以外にも以下の方法があります：

### スタートアップフォルダ

1. `Win + R` → `shell:startup` → Enter
2. `so8t_power_on_startup.bat` のショートカットを配置

### サービス化

より高度な制御が必要な場合、Windowsサービスとして登録することも検討してください。

## サポート

問題が発生した場合：

1. ログファイル（`logs/startup/`）を確認
2. イベントビューアーでシステムログを確認
3. Python環境とGPUドライバを確認
4. 必要に応じて手動実行でテスト

---

**注意**: このシステムはWindows専用です。LinuxやmacOSでは対応していません。
