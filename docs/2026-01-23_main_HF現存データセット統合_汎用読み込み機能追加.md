## 設計判断

### 1. 汎用読み込み機能
- **理由**: 任意のHugging Faceデータセットを学習に使用可能にする
- **実装**: データセット情報を自動取得し、適切なsplitを選択
- **メモリ最適化**: サンプル数を自動制限（デフォルト10,000）

### 2. フォールバック機能
- **理由**: 既知のデータセットの特別処理を維持しつつ、未知のデータセットも読み込める
- **実装**: エラー時に汎用読み込みを自動試行

### 3. データセット発見スクリプト
- **理由**: 人気のあるデータセットを自動的に発見・統合
- **実装**: Hugging Face Hub APIを使用（要インストール: `pip install huggingface_hub`）

## 使用方法

### 1. 汎用読み込み機能の使用

任意のHugging Faceデータセットを`config/dataset.json`に追加するだけで読み込めます：

```json
{
  "sources": [
    "huggingface:任意のデータセットID"
  ]
}
```

### 2. データセット発見スクリプトの使用

```bash
# 人気データセットを発見・検証・統合
py -3 scripts/data_processing/discover_hf_datasets.py \
  --task-types text-generation question-answering instruction-tuning \
  --min-downloads 5000 \
  --max-results 50 \
  --update-config \
  --generate-report
```

**注意**: `huggingface_hub`のインストールが必要です：
```bash
pip install huggingface_hub
```

### 3. データパイプラインの実行

```bash
# データセットをダウンロード・処理
py -3 scripts/data_processing/dataset_pipeline.py
```
