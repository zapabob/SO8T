## 目的

SO8Tリポジトリで「電源投入/ログオン時にPythonが自動再開する」仕掛けを停止する。

## 対応内容

### 1) 既存の自動起動経路（Windows）

- **Task Scheduler (schtasks)** により ONLOGON で Python/バッチが起動する構成が存在
- **Startup フォルダの .lnk** によりログオン時に監視/パイプラインが起動する構成が存在

### 2) “今後勝手に復活しない”ためのガード追加（デフォルト無効）

以下のスクリプトは、環境変数 `SO8T_ENABLE_AUTOSTART=1` を明示しない限り **何もしない（exit）** ように変更：

- `scripts/startup/setup_task_scheduler.bat`
- `scripts/startup/setup_advanced_science_task_scheduler.bat`
- `scripts/startup/setup_aegis_task.bat`
- `automation/setup_ab_test_automation.bat`
- `scripts/utils/setup_auto_resume_task.bat`
- `scripts/utils/setup_gguf_conversion_auto_resume.bat`

また、タスクが残っていてもPythonが走らないよう、起動側も kill-switch を追加：

- `scripts/startup/so8t_power_on_startup.bat`
- `scripts/startup/advanced_science_pipeline_startup.bat`

### 3) 自動起動タスク削除用スクリプト

- `scripts/startup/disable_autostart_tasks.ps1`
  - 管理者権限で実行して Task Scheduler を削除（必要なら Startup ショートカットも削除）

## 使い方（管理者で）

```powershell
cd C:\Users\downl\Desktop\SO8T
powershell -ExecutionPolicy Bypass -File .\scripts\startup\disable_autostart_tasks.ps1 -RemoveStartupShortcuts
```

## 重要

- 自動起動の“停止”のみで、学習/評価/変換パイプライン自体は削除していない。
- 意図的に自動起動を再有効化したい場合は、実行前に `SO8T_ENABLE_AUTOSTART=1` を設定する。
