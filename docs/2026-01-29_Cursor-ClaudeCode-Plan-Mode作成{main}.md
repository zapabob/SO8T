## ベストプラクティス

### 計画設計
1. **ステップを集中させる**: 各ステップは1つの明確な結果を達成
2. **依存関係で順序付け**: 依存ステップの前に依存関係を完了
3. **検証を含める**: 常に検証/テストステップを含める
4. **現実的に見積もる**: 計画のための時間見積もりを提供
5. **リスクを識別**: 特別な注意が必要な高リスクステップをマーク

### 実行
1. **頻繁に更新**: 作業の進捗に応じてtodosを更新
2. **チェックポイントを保存**: 自動チェックポイント保存が機能することを確認
3. **必要に応じてリサーチ**: リサーチステップをスキップしない
4. **エラーを適切に処理**: リトライとフォールバックメカニズムを使用
5. **変更を文書化**: 計画修正と理由をログに記録

### リサーチ統合
1. **計画前にリサーチ**: まずコンテキストを収集
2. **ステップごとにリサーチ**: 必要に応じてステップ固有のリサーチを実施
3. **仮定を検証**: リサーチを使用してアプローチを検証
4. **マルチソース検証**: 複数のソースから相互参照
5. **リサーチを集中させる**: 単純なステップを過度にリサーチしない
