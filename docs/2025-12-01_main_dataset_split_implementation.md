## 設計判断

### データセット構造の適応
- 既存データセットに要求された `domain` と `score` フィールドが存在しなかったため、新規作成
- phi35_label を以下のルールで domain にマッピング:
  - "math" → "math"
  - "physics" → "physics"
  - その他 → 確率的に "math"/"physics"/"reasoning" に分配

### 分割アルゴリズムの選択
- **層化抽出**: scikit-learn の StratifiedShuffleSplit を使用し、ドメイン比率を維持
- **難問優先**: PPO学習の効果を最大化するため、高スコア難問を強制的にPPOに割り当て
- **基礎固め**: SFTには中間レベルの良質データを優先的に割り当て

### 割合調整ロジック
- **理論的根拠**: 難問ほど強化学習の効果が高いため、PPOに80%を割り当て
- **実践的考慮**: SFTで基礎を固めた上で、PPOで深さと正確性を強化
- **最終調整**: SFT:PPO ≈ 1:4 の比率を達成 (19.6%:78.4%)

## テスト結果

### 分割結果統計
```
全体データ: 70,000件
├── SFT (19.6%): 13,720件 - 中難易度 (スコア: 0.320-0.480)
├── PPO (78.4%): 54,880件 - 全難易度 (スコア: 0.100-0.950)
└── Test (2.0%): 1,400件 - 完全未知データ
```

### ドメイン分布維持
- **SFT**: math 60.4%, reasoning 39.6% (基礎学習重視)
- **PPO**: physics 37.4%, reasoning 39.9%, math 22.7% (多様な難問)
- **Test**: 元データの比率を維持 (30.2% math, 29.9% physics, 39.9% reasoning)
