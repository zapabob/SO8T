## 設計判断

### I-Matrix方式の採用理由
- SO(8)アダプターの幾何学的構造（回転対称性）が量子化誤差で破壊される問題を解決するため
- 従来のGGUF量子化では数学能力が激減していたため、重要度行列による保護が必要
- 数学・論理推論中心のキャリブレーションデータで、SO(8)アダプターの重要な重みを優先的に保護

### チェックポイントシステムの設計
- GGUF変換は長時間実行されるため、中断耐性が重要
- 3分間隔は十分な頻度であり、データ損失を最小限に抑制
- 5個ローリングストックでストレージ容量を最適化
- JSON形式で完全な変換状態を保存可能

### 自動復旧機能の実装
- 電源断やシステム異常からの復旧を完全自動化
- Windows Task Scheduler連携で運用効率を向上
- 中間ファイル存在チェックによるスマート復旧判断
