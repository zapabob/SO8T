## 機能詳細

### 主要機能
1. **リアルタイムログ監視**: ログファイルを継続的に監視し、新しい行を即時表示
2. **ウィンドウ最前面表示**: PowerShellウィンドウを常時最前面に維持
3. **パイプラインステータス解析**: ログから現在の実行ステージと進捗を解析
4. **システムリソース表示**: CPU/メモリ/GPU使用率をリアルタイム表示
5. **色分け表示**: エラー・警告・成功メッセージを色分けして表示

### 使用方法
```powershell
# 基本実行
.\scripts\utils\show_pipeline_progress_realtime.ps1

# オプション指定
.\scripts\utils\show_pipeline_progress_realtime.ps1 -NoAudio -NoTopMost -LogFile "custom.log" -UpdateInterval 5
```

### パラメータ
- `-NoAudio`: 完了時の音声通知を無効化
- `-NoTopMost`: ウィンドウ最前面表示を無効化
- `-LogFile`: 監視するログファイル名を指定
- `-UpdateInterval`: 更新間隔（秒）を指定

## 運用注意事項

### データ収集ポリシー
- ローカルログファイルからの情報収集のみ実施
- 外部ネットワークアクセスは行わない
- 個人情報・機密情報の収集・表示は行わない

### NSFWコーパス運用
- パイプライン実行状況の監視に特化
- 安全判定ログの監視・表示が可能
- モデル生成コンテンツの直接表示は行わない

### /thinkエンドポイント運用
- パイプライン実行ログの監視に使用
- Thinking部（`<think-*>`）の内容はログに含まれないため非公開を維持
- Final出力のみがログに記録される想定
