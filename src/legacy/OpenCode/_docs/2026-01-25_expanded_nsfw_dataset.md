
# NSFW検知用データセット拡張タスク完了報告

- **日付**: 2026-01-25
- **機能名**: NSFW検知用データセットの拡張
- **実装者**: AI Agent

## 概要

ユーザーからの「より広範なNSFWデータが欲しい」という追加の指示に基づき、既存の`nsfw_detection_dataset.jsonl`を拡張するタスクを実行した。

## 実行内容と結果

### 1. データ収集戦略の再設定

- **課題**: Wikipediaの記事を一つずつ手動で選択する方法では、データの量と多様性に限界があった。
- **新戦略**: より大規模で多様なテキストデータを収集するため、データソースとしてRedditを採用。健全なコミュニティと、罵詈雑言や大人の話題が含まれやすいコミュニティの両方をターゲットに設定した。
    - **SFWターゲット**: `r/askscience`, `r/explainlikeimfive`
    - **NSFWターゲット**: `r/AmItheAsshole`, `r/tifu`, `r/unpopularopinion`

### 2. データ抽出の試行と課題

- **試行**: `google_web_search`でターゲットとなるスレッドのURLを特定後、`web_fetch`ツールで直接コンテンツの抽出を試みた。
- **失敗**: `web_fetch`ツールがRedditの動的なページ構造に対応できず、コンテンツの直接抽出に失敗。これは以前から確認されていたツールの技術的制約が再度問題となった形。

### 3. 最終手段：検索結果スニペットの活用

- **ワークアラウンド**: コンテンツの直接抽出を断念し、`google_web_search`を実行した際に得られる**検索結果のスニペット（投稿タイトルや要約文）**をデータとして活用する方針に切り替えた。
- **データ整形**: この方法で、SFW/NSFWの両方を含む複数のテキスト断片を収集。これらに `Yes` / `No` のラベルを付与し、Deepseek-GLPO形式に整形した。

### 4. 最終的な成果物

- **`nsfw_detection_dataset.jsonl`**: 既存のデータに、Redditの検索結果から抽出した新しいデータを追加し、上書き保存した。これにより、データセットは以前より広範で多様なものになった。
- **`_docs/2026-01-25_expanded_nsfw_dataset.md`**: 本タスクの実行ログ。

## 結論

ツールの制約により、当初計画していたWebからの大規模な直接データ収集は困難であった。しかし、検索結果のスニペットをデータソースとして活用するという機転を利かせたアプローチにより、ユーザーの「より広範なデータセットが欲しい」という要求に、可能な範囲で応えることができた。
