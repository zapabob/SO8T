## 使用方法

### 1. データセット発見

```bash
# ドメイン知識データセットを発見
py -3.12 scripts/data_processing/discover_domain_datasets.py --generate-report
```

### 2. 非構造データ処理

```bash
# 官公庁白書をダウンロード・処理
py -3.12 scripts/data_processing/process_unstructured_data.py

# 特定ドメインのみ処理
py -3.12 scripts/data_processing/process_unstructured_data.py --domain 防衛
```

### 2.5. Arxiv/BioRxiv論文処理

```bash
# 引用上位10万件を処理（科学・数学推論能力向上用）
py -3.12 scripts/data_processing/process_arxiv_biorxiv.py --max-papers 100000

# カスタムクエリで検索
py -3.12 scripts/data_processing/process_arxiv_biorxiv.py --max-papers 50000 --query "machine learning"
```

### 3. ドメイン知識データ統合

```bash
# 全てのドメイン知識データを統合
py -3.12 scripts/data_processing/integrate_domain_knowledge.py --update-config
```

### 4. サンセットパイプライン実行

```bash
# 統合されたデータセットでサンセットパイプラインを実行
py -3.12 scripts/run_sunset_pipeline.py
```

## データ処理フロー

### 非構造データ処理フロー

1. **ダウンロード**: 官公庁サイトからPDFをダウンロード
2. **テキスト抽出**: PDFからテキストを抽出
3. **構造化**: テキストを構造化データに変換
4. **クレンジング**: データをサニタイズ・クレンジング
5. **保存**: JSONL形式で保存

### データ統合フロー

1. **非構造データ読み込み**: 処理済みの官公庁データを読み込み
2. **NSFW検知データセット読み込み**: HuggingFaceから読み込み
3. **薬物検知データセット読み込み**: 安全性データセットを読み込み
4. **サニタイズ**: 学習用データにサニタイズ
5. **統合**: 全てのデータセットを統合
6. **保存**: 統合データセットを保存
7. **設定更新**: dataset.jsonを更新

## 注意事項

### 非構造データ処理

- PDFダウンロードには時間がかかる場合があります
- 一部のPDFはテキスト抽出が困難な場合があります
- 機密情報のマスキングは簡略実装のため、必要に応じて拡張が必要です

### データセットの可用性

- 一部のHuggingFaceデータセットは利用できない場合があります
- 利用可能なデータセットのみを統合します
- 非構造データは事前に処理が必要です

### サニタイズ

- 機密情報のマスキングは基本的な実装です
- より高度なサニタイズが必要な場合は拡張が必要です

## 今後の拡張予定

1. **高度なPDF処理**: OCR対応、表・図の抽出
2. **機密情報検出**: より高度な機密情報検出・マスキング
3. **データ品質評価**: 自動的なデータ品質評価
4. **増分更新**: 既存データの増分更新機能

7. **引用ネットワーク分析**: 論文間の引用関係を活用した推論能力向上
8. **数式・定理抽出**: LaTeX形式の数式・定理を構造化
