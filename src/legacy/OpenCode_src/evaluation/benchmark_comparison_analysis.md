# SO8T AEGIS v2.5 ベンチマーク比較分析

## 概要

SO8T AEGIS v2.5 (SO8T四重推論 + imatrix保護適用済み) のベンチマークスコアを、他の主要なリアルLLMと比較した分析レポートです。

## 評価対象モデル

### AEGIS v2.5 スコア (2026年1月)
- **モデル**: AEGIS-Phi-3.5mini-jp-v2.5-SO8T-imatrix
- **特徴**: SO8T四重推論 + DeepSeek-R1 GRPO + mHC多様体 + 幾何学的スケーリング + imatrix保護
- **パラメータ**: 4B (Phi-3.5-miniベース)
- **評価日**: 2026-01-20
